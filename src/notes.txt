openssh on a windows machine

Step 1: Enable the Built-in OpenSSH Server on Windows
Modern Windows 10 and 11 include Microsoft's official OpenSSH Server natively (no third-party software needed). Run these commands in an Administrator PowerShell window on your Windows PC:
powershell
# 1. Install the OpenSSH Server feature
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

# 2. Start the SSH/SFTP service and set it to launch automatically at boot
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'

# 3. Verify the Windows Firewall rule for port 22 is active
Get-NetFirewallRule -Name *ssh*

Step 2: Set Up Passwordless SSH Key Auth (So Your Bash Script Won't Hang)

For a bash script on RHEL to run unattended without prompting for a Windows password:
1. On RHEL: Generate an SSH key (if you don't already have ~/.ssh/id_ed25519.pub):bash
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
cat ~/.ssh/id_ed25519.pub

2. On Windows:
	If your Windows user is a standard user, append that public key line to C:\Users\<YourWindowsUser>\.ssh\authorized_keys.
	If your Windows user is an Administrator (most common), Windows OpenSSH reads keys from C:\ProgramData\ssh\administrators_authorized_keys insteadappend the public key there and lock down its permissions in Admin PowerShell:powershell
icacls.exe "C:\ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"
Use code with caution.

Step 3: Pull Files in Your RHEL Bash Script (scp or rsync)

Once sshd is running on Windows, your RHEL bash script can pull files using standard scp (or rsync if you install cwRsync on Windows, though scp works out of the box):
bash
#!/usr/bin/env bash
set -euo pipefail

WIN_USER="billt"
WIN_HOST="192.168.1.50"   # Your Windows PC's local IP or hostname
WIN_PATH="C:/jboa-rsi/logs/"
RHEL_DEST="/home/billt/jboa-1/win_logs/"

mkdir -p "${RHEL_DEST}"

# Copy a single file
scp "${WIN_USER}@${WIN_HOST}:C:/jboa-rsi/parms.ini" "${RHEL_DEST}"

# Or recursively copy an entire folder
scp -r "${WIN_USER}@${WIN_HOST}:${WIN_PATH}" "${RHEL_DEST}"
Use code with caution.
(Note: Use forward slashes C:/... in the remote Windows path so Bash doesn't treat backslashes as escape characters.)

Alternative: Push from RHEL to Windows (Even Simpler)

If you already use WinSCP on Windows, remember that RHEL already runs an OpenSSH server (sshd) by default. Instead of pulling from Windows, you can:
 Push files from your RHEL bash script straight to Windows (scp localfile winuser@winhost:C:/... once Windows sshd is on), or
 Run a WinSCP script / Windows Task Scheduler job on Windows to pull from RHEL (winscp.com /script=...), requiring zero changes to Windows services.
Are you trying to automate a scheduled pull on RHEL (via cron or a systemd timer), or would you prefer to push/pull using a Windows SMB network share (mount -t cifs) instead of SSH?
